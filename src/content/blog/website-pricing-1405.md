# قیمت طراحی سایت در ۱۴۰۵ چقدره؟ راهنمای شفاف

سؤالی که هر روز ازم پرسیده می‌شه:

> «طراحی سایت چقدر هزینه داره؟»

و جوابی که هر روز می‌دم:

> «بستگی داره. بین ۳ میلیون تا ۳۰۰ میلیون.»

**این جواب کسی رو قانع نمی‌کنه. پس بذار کامل توضیح بدم.**

## چرا قیمت‌ها اینقدر فرق دارن؟

فرض کن می‌خوای ماشین بخری. یکی می‌گه «پراید ۳۰۰ میلیون»، یکی می‌گه «بنز ۳۰ میلیارد».

**هیچ‌کس نمی‌پرسه چرا فرق دارن؟ چون منطقیه.**

سایت هم همینه. سایت یه **محصول فیزیکی** نیست — یه **سرویس** ئه. کیفیت، سرعت، امکانات، پشتیبانی، همه چیز توی قیمت تأثیر داره.

## ۶ سطح سایت (و قیمت هر کدوم)

### 🟢 سطح ۱: لندینگ ساده — ۳ تا ۸ میلیون

**چیه؟** یه صفحه‌ی تک‌اسکرول که محصول یا خدمتت رو معرفی می‌کنه.

**مناسب برای:**

- مدرس‌ها، کوچ‌ها
- رویدادها، کمپین‌های تبلیغاتی
- کسب‌وکارهایی که فقط می‌خوان «حضور آنلاین» داشته باشن

**چی داره؟**

- یه صفحه
- فرم تماس
- لینک به شبکه‌های اجتماعی
- دکمه CTA

**چی نداره؟**

- بلاگ
- پنل مدیریت
- فروشگاه

**زمان:** ۳-۷ روز

---

### 🟢 سطح ۲: سایت شرکتی — ۸ تا ۲۰ میلیون

**چیه؟** سایت چندصفحه‌ای برای معرفی شرکت، خدمات، تیم و نمونه‌کار.

**مناسب برای:**

- شرکت‌های خدماتی
- کلینیک، مطب، آموزشگاه
- استودیوهای طراحی

**چی داره؟**

- ۵-۱۰ صفحه
- صفحه‌ی خدمات با جزئیات
- نمونه‌کار یا گالری
- صفحه‌ی درباره ما
- فرم تماس پیشرفته
- بلاگ پایه
- نقشه‌ی سایت

**چی نداره؟**

- فروشگاه آنلاین
- سیستم کاربر
- پرداخت آنلاین

**زمان:** ۲-۴ هفته

---

### 🟡 سطح ۳: سایت فروشگاهی — ۲۰ تا ۶۰ میلیون

**چیه؟** فروشگاه آنلاین با سبد خرید، پرداخت، مدیریت محصول.

**مناسب برای:**

- فروشگاه‌های فیزیکی که می‌خوان آنلاین هم بفروشن
- برندهای پوشاک، لوازم خانگی، دیجیتال
- کسب‌وکارهای محصول‌محور

**چی داره؟**

- همه‌ی امکانات سطح ۲
- سیستم مدیریت محصول (پنل ادمین)
- سبد خرید
- درگاه پرداخت (زرین‌پال، آیدی‌پی)
- سیستم کد تخفیف
- مدیریت سفارش
- فیلتر پیشرفته
- جستجو

**چی نداره؟**

- سیستم اختصاصی
- اپلیکیشن

**زمان:** ۴-۸ هفته

---

### 🟡 سطح ۴: سایت اختصاصی — ۶۰ تا ۱۵۰ میلیون

**چیه؟** سایتی که از صفر برای نیاز **خاص** کسب‌وکار تو طراحی می‌شه.

**مناسب برای:**

- استارتاپ‌ها با مدل کسب‌وکار خاص
- پلتفرم‌های SaaS
- سایت‌هایی با نیاز فنی پیچیده

**چی داره؟**

- همه‌ی امکانات قبلی
- سیستم کاربر و پروفایل
- داشبورد اختصاصی
- API اختصاصی
- یکپارچه‌سازی با سیستم‌های خارجی
- اتوماسیون workflow
- گزارش‌گیری

**زمان:** ۲-۶ ماه

---

### 🔴 سطح ۵: پلتفرم بزرگ — ۱۵۰ تا ۵۰۰ میلیون

**چیه؟** پلتفرم‌های بزرگ با میلیون‌ها کاربر.

**مناسب برای:**

- مارکت‌پلیس‌ها (مثل دیجی‌کالا، اسنپ)
- سیستم‌های B2B پیچیده
- پلتفرم‌های چندنقشی

**چی داره؟**

- همه چیز
- معماری مقیاس‌پذیر
- تیم توسعه (نه یه نفر)
- DevOps، تست، امنیت

**زمان:** ۶ ماه تا ۲ سال

---

### 🔴 سطح ۶: سازمانی — بالای ۵۰۰ میلیون

**مناسب برای:** بانک‌ها، بیمه‌ها، سازمان‌های بزرگ.

**این سطح رو ولش. تو این سطح کار نمی‌کنی.**

## عواملی که قیمت رو عوض می‌کنن

بذار بگم **دقیقاً** چی قیمت رو بالا/پایین می‌بره:

### 🎨 طراحی (۳۰٪ قیمت)

| چی | قیمت |
|----|------|
| قالب آماده | ارزون |
| طراحی اختصاصی ساده | متوسط |
| طراحی اختصاصی + انیمیشن | گرون |
| طراحی با هویت بصری کامل | خیلی گرون |

### ⚙️ امکانات فنی (۴۰٪ قیمت)

هر امکان فنی که اضافه می‌شه، قیمت رو می‌بره بالا:

- فرم ساده → رایگان
- سیستم کاربر → +۵ تا ۱۰ میلیون
- درگاه پرداخت → +۵ تا ۱۵ میلیون
- پنل ادمین → +۱۰ تا ۳۰ میلیون
- یکپارچه‌سازی API → +۱۰ تا ۵۰ میلیون

### 🚀 سرعت و کیفیت (۱۵٪ قیمت)

- سرعت لود زیر ۲ ثانیه → +۱۰٪
- تست کامل روی همه مرورگرها → +۵٪
- بهینه‌سازی سئو → +۱۰٪

### 🛡️ امنیت (۱۰٪ قیمت)

- SSL → معمولاً رایگان
- محافظت از حمله → +۵٪
- بک‌آپ خودکار → +۳٪
- تست امنیتی → +۱۰٪

### 🤝 پشتیبانی (۵٪ قیمت)

- بدون پشتیبانی → ۰
- پشتیبانی ۱ ماهه → +۵٪
- پشتیبانی ۶ ماهه → +۱۵٪
- پشتیبانی ۲۴/۷ → +۳۰٪

## یه مثال واقعی

**یه مشتری می‌گه:** «سایت فروشگاهی برای ۱۰۰ محصول می‌خوام.»

**سؤال‌هایی که می‌پرسم:**

1. **پنل ادمین می‌خوای؟** (بله/خیر — ۱۵ میلیون فرق)
2. **درگاه پرداخت کدوم؟** (زرین‌پال رایگانه، اختصاصی ۵ میلیون)
3. **موبایل‌فرندلی طراحی کنم؟** (بدیهیه — رایگان)
4. **سیستم تخفیف می‌خوای؟** (بله/خیر — ۳ میلیون فرق)
5. **چند محصول داری؟** (۱۰۰ تا که راحته، ۱۰۰۰۰ تا فرق می‌کنه)

**نتیجه:** بین **۲۵ میلیون** تا **۵۰ میلیون**.

## قیمت‌هایی که باید ازش فرار کنی

### 🚩 «طراحی سایت فقط ۵۰۰ هزار تومان!»

**یعنی چی؟** قالب آماده، بدون تغییر، بدون پشتیبانی. پولت رو می‌دی، بعدش هیچی.

### 🚩 «قیمت‌ها توی مشاوره معلوم می‌شه»

**یعنی چی؟** می‌خوان ببینن چقدر می‌تونی بدی، بعد قیمت بگن.

**پیشنهاد:** از **قبل** قیمت محدوده بخواه.

### 🚩 «سایت + سئو + تبلیغات فقط ۱۰ میلیون»

**یعنی چی؟** هیچ‌کدومشون درست انجام نمی‌شه. **ماهی رو که از آب بگیری تازه‌ست، ولی اینجا تخم‌مرغ رو فروختن.**

## چه‌طوری از قیمت بالا رفتن جلوگیری کنم؟

### ۱. لیست امکاناتت رو مشخص کن

**قبل از مشاوره**، بنویس:

- چیکار می‌خوام سایت بکنه؟
- چه امکاناتی **حتماً** لازمه؟
- چه امکاناتی **خوبه اگه بود**؟
- چه امکاناتی **لازم ندارم**؟

### ۲. از فاز اول شروع کن

**همه چیز رو یه‌جا نگیر.** مثلاً:

- **فاز اول:** سایت اصلی + فرم تماس
- **فاز دوم:** سیستم کاربر
- **فاز سوم:** پنل ادمین

اینطوری:

- هزینه‌ت پخش می‌شه
- سریع‌تر سایتت بالا میاد
- می‌تونی نظرات کاربر رو بگیری قبل از توسعه

### ۳. قیمت‌های چند جا رو بگیر

**حداقل از ۳ جا** بپرس. اگه همه یه چیزی گفتن، قیمت منطقیه. اگه یکی خیلی کمتره، **بپرس چرا**.

## چرا من؟

قبل از اینکه به سایت من بیای، **به هر کسی که می‌خوای** برو.

**ولی اینا رو چک کن:**

1. **نمونه‌کارهای واقعی** داره یا عکس‌های استوک؟
2. **نظر مشتری‌ها** رو می‌تونی ببینی؟
3. **قیمت شفاف** ئه یا «توی مشاوره»؟
4. **پشتیبانی** بعد از تحویل چطوره؟
5. **سایت خودش** چطوره؟ (اگه سایت خودش ضعیفه، سایت تو چطور می‌سازه؟)

## محاسبه‌ی واقعی ROI

یه سایت ۲۰ میلیونی که ماهی ۵ مشتری جدید بیاره:

- ۵ مشتری × ۵ میلیون = **۲۵ میلیون در ماه**
- سایتت توی **۱ ماه** خودش رو جبران می‌کنه

**می‌بینی؟ سایت یه هزینه نیست، یه سرمایه‌گذاریه.**
