# چرا ۷۰٪ کاربران موبایل، سایتت رو در ۳ ثانیه ترک می‌کنن؟

فرض کن ۱۰۰ نفر وارد سایتت می‌شن. ۷۰ نفرشون از موبایل میان. از این ۷۰ نفر، ۵۶ نفر — یعنی بیشتر از نصف — توی ۳ ثانیه‌ی اول برمی‌گردن.

دلیلش همیشه هم کیفیت محصولت نیست. بیشتر وقت‌ها دلیل اینه: سایتت روی موبایل کار نمی‌کنه.

## تست سریع — گوشیت رو بردار

قبل از هر چیز، این تست ۶۰ ثانیه‌ای رو انجام بده:

۱. با گوشی خودت سایتت رو باز کن
۲. **بدون زوم**، چک کن:
- [ ] همه‌ی متن‌ها بدون زوم خوانا هستن؟
- [ ] دکمه‌ها به‌اندازه‌ی کافی بزرگ هستن؟
- [ ] اسکرول افقی نداری (یعنی صفحه فقط بالا-پایین می‌ره)؟
- [ ] فرم‌ها راحت پر می‌شن؟
- [ ] سرعت لود زیر ۳ ثانیه‌ست؟

اگر حتی یکی از این‌ها مشکل داشت، این مقاله برای توئه.

## ۷ مشکل رایج و راه‌حل هرکدام

### ۱. فونت‌های ریز

استاندارد جهانی برای متن روی موبایل، حداقل **۱۶ پیکسل** است. اگر فونتت کوچیک‌تره، کاربر باید زوم کنه — و زوم کردن یعنی خروج.

**راه‌حل:** یک تابع کوچک بنویس که همه‌ی فونت‌های بدنه رو حداقل ۱۶ پیکسل نگه‌داره.

### ۲. دکمه‌های کوچک

استاندارد Apple و Google: هر دکمه یا لینک باید حداقل **۴۸ در ۴۸ پیکسل** باشه. کمتر از این، انگشت کاربر خطا می‌کنه.

**راه‌حل:** به هر دکمه‌ی موبایل یک 'min-height: 48px' و 'min-width: 48px' بده.

### ۳. اسکرول افقی

اگر کاربر مجبور باشه چپ-راست اسکرول کنه تا محتوا رو ببینه، همون لحظه سایتت رو می‌بنده.

**راه‌حل:** همه‌ی عکس‌ها باید `max-width: 100%` باشن. جدول‌های عریض باید به یک container با `overflow-x: auto` پیچیده بشن.

### ۴. پاپ‌آپ‌های آزاردهنده

یک پاپ‌آپ تبلیغاتی که روی موبایل نصف صفحه رو می‌پوشونه، بدترین چیز ممکنه.

**راه‌حل:** روی موبایل، پاپ‌آپ‌ها رو حذف کن یا به یه نوار باریک پایین صفحه تبدیل کن.

### ۵. فرم‌های سخت

هر فیلد فرم باید **input type** درست داشته باشه — `tel` برای شماره، `email` برای ایمیل، `number` برای عدد. این کار کیبورد مناسب رو باز می‌کنه.

**راه‌حل:** برچسب‌های فرمت رو حذف کن، کیبورد خودکار درست رو باز کن.

### ۶. سرعت پایین

روی موبایل، حتی اینترنت ۴G هم می‌تونه کند باشه. هر ۱ ثانیه تأخیر، **۷٪ کاهش نرخ تبدیل** می‌سازه.

**راه‌حل:** تصاویر WebP، حذف JavaScript اضافه، هاست نزدیک به کاربر.

### ۷. منوی موبایل بی‌کیفیت

منوی همبرگری که فقط با هاور کار می‌کنه روی موبایل بی‌فایده‌ست. کاربر موبایل «لمس» می‌کنه، نه «هاور».

**راه‌حل:** منوی موبایل باید با لمس کار کنه، با انگشت باز بشه، و بسته شدنش راحت باشه.

## چک‌لیست نهایی — ۱۰ مورد

قبل از انتشار سایتت، این ۱۰ مورد رو چک کن:

- [ ] فونت‌ها حداقل ۱۶ پیکسل
- [ ] دکمه‌ها حداقل ۴۸ پیکسل
- [ ] بدون اسکرول افقی
- [ ] سرعت لود زیر ۳ ثانیه
- [ ] فرم‌ها با input type درست
- [ ] عکس‌ها ریسپانسیو
- [ ] منوی موبایل لمسی
- [ ] پاپ‌آپ‌ها قابل بستن راحت
- [ ] متن‌ها بدون زوم خوانا
- [ ] تست‌شده روی حداقل ۲ گوشی واقعی

## ابزار رایگان برای تست

- **Chrome DevTools** → `F12` → `Ctrl+Shift+M` → iPhone 12 Pro
- **PageSpeed Insights** → سرعت واقعی روی گوشی‌های مختلف
- **WebPageTest** → تست سرعت روی شبکه‌های کند

اما بهترین تست اینه: **گوشی خودت رو بردار و سایتت رو باز کن.** اگر خودت راحت نیستی، مشتری هم راحت نیست.
